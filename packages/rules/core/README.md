# SecretShield Core Rule Pack

Official first-party detection rule pack for SecretShield.

- **Pack ID**: `core-rules`
- **Version**: `1.0.0`
- **License**: `Apache-2.0`
- **Precedence Tier**: Tier 1 (Highest priority built-in rules)

2. **AI**: OpenAI, Anthropic, HuggingFace
3. **Source Control**: GitHub, GitLab

5. **Communication**: Slack, Twilio, SendGrid, Discord
6. **Databases**: PostgreSQL, MongoDB, Redis, MySQL
7. **Infrastructure**: HashiCorp Vault, Terraform Cloud
8. **CI/CD**: GitHub Actions, CircleCI
9. **Authentication**: JSON Web Tokens (JWT), OAuth
10. **Private Keys**: RSA, OpenSSH, PGP, EC
11. **Tokens**: NPM, Bearer tokens
12. **Generic Secrets**: High-entropy API keys, passwords
13. **Configuration Secrets**: Dotenv credentials

# Multi-Agent Teamwork & Peer Review Orchestration

Coordinate multiple specialized agents to analyze, build, audit, and verify software systems in parallel.

## Coordination Framework

1. **Role Specialization**:
   - Coordinator: Deconstructs tasks, assigns roles, and reconciles final outputs.
   - Auditor/Reviewer: Inspects code quality, security boundaries, and adherence to production standards.
   - Implementer: Carries out targeted fixes with minimal diffs and verified unit tests.
2. **Shared State & Message Board**: Communicate structured milestones, verification logs, and blockers.
3. **Peer Review**: Every modification must be reviewed and tested against regressions before acceptance.

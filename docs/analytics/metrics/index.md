# Analytics Metrics

## open_findings
Count of observed finding events with status OPEN.

## critical_findings
Count of observed finding events with severity CRITICAL.

## dependency_vulnerabilities
Count of dependency events observed in the selected day or range.

## policy_violations
Count of policy events whose status is not PASSED.

## remediation_backlog
Count of remediation events still pending verification or closure.

## incidents
Observed incident events in the scope.
